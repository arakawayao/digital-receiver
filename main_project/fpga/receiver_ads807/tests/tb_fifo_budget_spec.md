# tb_fifo_budget

仅用于仿真的 FIFO 容量隔离检查，不连接实板、不代表 USB 端到端结果。

- DUT 为三模式工程的 `rx_fifo_tri`，使用实际 Intel `dcfifo` 模型。
- 写时钟 43.5 MHz，每 87 周期产生一个 I/Q 样本，即 500 kS/s；读时钟 24 MHz。
- 全局低有效复位连接 FIFO aclr；复位释放后等待 20 us，再开始产生样本。
- 输入 288 位：高 192 位清零，随后 dropped32/index32/Q16/I16；与实际链路低 96 位布局相同。
- 从空 FIFO 开始暂停读取 250/500/750/1000/2000/5000 us，写端始终持续，满时丢新样本并累计 dropped。
- 恢复读取后继续产生 150 us，再停止输入并排空；逐字核对全部成功入队数据。
- 暂停阶段预期丢样为 max(实际产生样本数 - DEPTH, 0)，不将已知注入故障描述为零丢样。
- 校验序号间断、上报丢样、总产生 = 成功入队 + 丢弃，以及恢复后的顺序与数据完整性。
- DEPTH 与每次编译的包装参数同步设置；512 点为仿真对照，未综合或烧录。
- 不包含打包器、FX2 缓冲、USB 总线、操作系统或 GUI，无法由此推算实际主机停顿时长。
