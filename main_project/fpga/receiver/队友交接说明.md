# FPGA 接收工程交接

目标器件：Cyclone IV E EP4CE6F17C8；目标 Quartus Prime Lite 20.1。板载参考时钟 24 MHz。实际 ADC 工程面向 ACM2108，用户确认 FPGA 接入 8 位数据总线（另两位未接），PLL 提供 32 MHz Encode Clock；USB 回放工程仍保留 56 MHz/12 位链路。

## 选择工程

| 工程 | 顶层 | 输入 | 用途 | 已编译文件 |
|---|---|---|---|---|
| `receiver56.qpf` | `receiver_top` | ACM2108 8 位 ADC，32 MS/s | 实际 ADC 接收、自动选频和 I/Q 输出 | 新编译 `output_56/receiver56.sof`（含 Signal Tap） |
| `receiver_loop.qpf` | `receiver_loop_top` | USB EP6 OUT 上传的 ADC 测试样本 | 不接 ADC 的数字链路回环 | `output_loop/receiver_loop.sof` |

两套工程共用 `rtl/` 与 `ip/`，由 `ADC_RATE` 选择链路参数。当前环境用 Quartus 18.1 Standard 已完整编译带 Signal Tap 的 `receiver56`；工程目标版本记录为 Quartus 20.1.1 Lite。下载当前新 SOF 后按 [SIGNALTAP_ACM2108.md](SIGNALTAP_ACM2108.md) 采集。

## 信号与硬件约定

- 实际 ADC 目标为 ACM2108；用户确认接入 FPGA 的数据总线 8 位（另两位未接），FPGA 提供 32 MHz Encode Clock。RTL 当前按直二进制解释，需实测码型与位序。`ADC_INVERT` 默认 0；如确认板级数据线逐位反相，再设为 1。旧 SOF/旧 12 位 ADC 配置不能用于此版本。
- ADC 管脚与 3.3-V LVTTL 标准在 `adc_pins.tcl` 中；SDC 暂用 25 ns 最大数据延迟假设作为输入约束，但最小延迟暂取 0、PCB 时钟/数据偏斜未核实。编译成功不代表 ADC 接口时序已按实板签核。
- `receiver56` 自动选频按 RF=96 MHz−alias 估算 88–96 MHz 负混叠侧；零混叠点无法测频，检测器实际需至少约 1 MHz alias。四级半带 /16、111 tap FIR /4 后输出 500 kS/s signed16 I/Q。
- I/Q 跨时钟 FIFO 为 1024 × 97 位，约缓存 2.048 ms。长时间停止读取仍可能产生丢样。
- USB 使用 FX2 同步 Slave FIFO，EP6 OUT (`0x06`) 用于回环上传，EP2 IN (`0x82`) 用于应答与 I/Q。回环必须使用支持这两个端点和 indexed FLAG 的固件。

## 文件

`rtl/`：接收、自动选频、DDC、滤波、打包及 FX2 接口；`ip/`：PLL、异步 FIFO 和 IFCLK 输出 IP；`rtl/fir_coeff32.hex` 与 `rtl/fir_coeff56.hex` 分别供 32 MHz ADC 与 56 MHz 回放链路使用；`receiver.sdc`、`receiver_loop.sdc`：时序约束；`adc_pins.tcl`：ADC 引脚表；`scripts/generate.py` 和 `scripts/fir_design.py`：IP 与系数重新生成脚本。Quartus 工程已包含生成后的 IP/HEX，直接打开 QPF 不必先运行脚本。

`host/usb_replay.py` 与 `host/usb_transport.py` 是 USB 回环上位机脚本。已配置 Cypress 驱动且安装 `pythonnet` 时，可在 Python 脚本形参中使用：

```text
run --kind alternate --continuous --backend cyusb --fx2-init none --vid 0x04B4 --pid 0x1004 --frames 16 --output validation/my_alternate
```

该命令按 AM（默认请求 100.7 MHz）与 FM（默认请求 101.7 MHz）交替上传和验证，每回合之间短暂停止；按 Ctrl+C 结束。用 `--rf` 指定 AM 载频，用 `--fm-rf` 指定 FM 载频，单位 Hz。该回放顶层仍以 56 MHz 循环播放；它不能通过 USB 实时提供 ADC 样本。

## 检查范围

回环 SOF 对应 56 MHz 测试链路；ADC 工程已有包含 Signal Tap 的 32 MHz 新 SOF，由 Quartus 18.1 Standard 编译。目标工程设置为 Quartus 20.1.1 Lite；尚未完成实板采集和 ADC 时序签核。
