# rx_cic

固定 R87、五级 CIC，输入 signed24/valid，输出 signed18/out_valid/clipped。
clk=43.5 MHz，同步低有效复位；无反压。每 87 个有效输入抽取一次，
积分器和梳状器 59 位二补码模回绕，梳状器采集上升沿前的末级积分器值。
五级梳状流水后输出，算术右移 40 位向负无穷取整，饱和到 [-131072,131071]。
抽取计数按有效输入推进，梳状有效流水每拍推进；间断不得改变样本计数。
增益 87^5=4984209207，保守增长 33 bit，signed24+33=57 bit，59 bit 有余量。
整数参考逐拍比较 valid、码值、clip；包括回绕、间断、复位和输入边界。
