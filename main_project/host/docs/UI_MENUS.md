# 菜单与面板更新

日期：2026-10-21。依据：用户确认的菜单、面板勾选和参数弹窗预览。

## 实现范围

保留原有双侧栏、中心波形与底部日志/记录布局。
功能面板分别受“视图”勾选控制，中心波形不能隐藏；所有同侧面板隐藏后收起该侧栏。
日志和记录标签分别控制，全部隐藏时收起底部区域。
“仅显示波形”隐藏功能面板，保留工具栏和状态栏当前状态。
“恢复默认布局”恢复两侧栏位置、面板、工具栏、状态栏及日志标签，不修改信号参数。

| 菜单 | 入口 |
| --- | --- |
| 文件 | 回放文件、保存波形、记录目录、退出 |
| 视图 | 分组勾选功能面板、工具栏/状态栏、布局命令 |
| 采集 | 开始、停止、冻结显示、连接与数据源参数、载频调谐参数 |
| 分析 | 显示/FFT 参数、波形类型、复位视图、各分析结果面板 |
| 音频 | 输出参数、扬声器开关、刷新设备 |
| 记录 | 查找、刷新、目录选择、事件日志 |

菜单与工具栏共用开始/停止/保存等 QAction，状态随会话同步。
参数弹窗复制当前控件值，确认后写回，沿用现有 Qt signals/slots；取消不改变实际参数。
连接和调谐在运行中锁定，音频设备在输出期间锁定。
无新增依赖；协议、FPGA、DSP 算法、接收队列和音频实现保持原有版本。
本轮未新增跨次运行的布局保存。

## 软件验证

在 `D:\conda_envs\ads807_host\python.exe`、Windows / PyQt6 环境执行：

```powershell
python -B -m pytest tests -q -p no:cacheprovider --basetemp .harness/menu_regression --junitxml .harness/menu_regression.xml
python -B -m ads807.verify --output .harness/menu_verification
```

- 110 项测试通过，包括各面板显隐、波形空间扩展、隐藏时持续处理、菜单状态同步、
  弹窗确认/取消、手动调谐、运行中参数锁定、记录目录和原有波形缩放/保存/回放/关闭流程。
- AM、FM、无信号、噪声 4 个合成场景通过；校验和连续性检查通过。
- 实际 Qt 截图覆盖 1440×940 和 1100×760，并生成解调、FFT、I/Q 画面。
- 证据：`.harness/menu_regression.xml`、`.harness/menu_verification/result.json` 及同目录 PNG。

以上为离线软件验证；本轮未连接真实 USB、输入射频或输出物理音频。
右侧实时镜像来自 Qt 窗口，浏览器提供波形标签切换；完整菜单及弹窗交互在桌面程序中进行。

短时测试通过后，另启动持续 AM 合成镜像时观察到接收队列溢出和连续性异常，
状态与完整性面板会如实显示，波形在连续缓存重新建立前可能清空。
本轮未定位其原因或修改处理链路，不能将短时合成验证通过解释为持续无丢样通过。
镜像运行时的计数快照见 `.harness/menu_preview_health.json`；持续吞吐仍需独立排查及验证。
