# 解调模式配置

2026-10-27。输入仍为 FPGA 的 500 kIQ/s、signed16 I/Q，小端 I 后 Q，
转换为 I+jQ / 32768；输出仍为单声道 48 kHz。没有修改 FPGA、USB 协议或载频设置。

## 操作

- “分析 → 解调模式”菜单或右侧“调制识别 → 解调模式”下拉框。
- 参数弹窗入口为“分析 → 解调参数…”或调制识别面板的配置按钮。
- 默认“自动识别”，可选“强制 AM”“强制 FM”，运行中可切换。
- 停止后重启采集保留当前选择；退出软件后重新启动恢复自动。

FM 去加重在音频面板提供关闭、50、75、100、150、200、300 µs；50/75 µs 是广播常用时间常数，
100 µs 以上为实验档位。去加重是 FM 音频的一阶低通补偿，时间越长，高频衰减越明显；
不会改变 I/Q、FFT、自动识别或载频测量。保存的 `deemphasis_us` 记录实际值。

自动模式保持现有分类与静音策略。强制模式绕过自动分类对音频的准入：
连续有效的 I/Q 即使被判为未知、低电平或带削顶标志，仍按用户选择做 AM 包络或 FM 鉴频。
它不更改 Measurement.kind、不伪造置信度或参数，右侧同时显示自动结果与实际解调方式。
不因强制模式中的 AM/FM/未知分类变化清空音频；否则弱信号仍会断续。

帧解析与 CRC、样本序号、丢样、削顶、断连监测继续工作；间断重置滤波状态，
断流不合成替代样本。切换解调模式时清除旧音频和历史、重置滤波并重新预热，
避免同一 WAV 混入不同解调模式。有效数据恢复后仍有原有的滤波预热与音频预缓冲。
强制模式可能输出噪声，也可能输出真实零值；这不是接收节目成功的保证。

## 保存

metadata.json 新增 demodulation：mode 为 auto/AM/FM，kind 为实际处理类型，
forced 为是否强制。measurement 保留自动结果。模式快照来自已经处理的块，
而不是界面尚待应用的选项。记录列表在自动类型后附加强制方式，支持按“强制 FM”等查找。
旧记录缺少此字段仍按自动记录读取。读取 transport.fcr 回放时，由当前选择决定解调方式。
