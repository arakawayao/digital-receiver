# FM 解调波形修复

2026-10-25，针对 USB 实测 FM 输入只有零水平线的问题完成一次算法修复。

现象是 I/Q 和 FFT 有数据，但 FM 测量字段为空。原识别器先要求相邻样本相位相干度不低于 0.8、
频谱集中度不低于 0.55；宽带 FM 的能量分散、瞬时频偏较大，可能被提前判为“未知”。
未知类型进入解调器后会输出静音，这是防止把噪声强制判成 AM/FM 的原有保护逻辑。

现在保留原窄带 FM 路径，并增加宽带 FM 和低频偏单音 FM 路径：同时满足恒包络、相位变化明显、
可识别频偏音调和最低频谱能量条件时判为 FM。调制频率 500 Hz、频偏 100 Hz 的信号属于低频偏路径。
复噪声的包络变化、纯载波的频偏不足和低电平信号仍保持“未知/无有效信号”。

验证：

```powershell
python -B -m pytest tests -q -p no:cacheprovider --basetemp .harness/fm_fix_full
python -B -m ads807.verify --output .harness/fm_fix_verification
```

结果：完整测试通过；AM、FM、无信号和噪声四种离线场景通过；新增 75 kHz 宽带 FM、低频偏单音 FM
识别和非零解调输出测试通过。
上述结果不包含真实 USB、射频输入和物理扬声器验收。重启程序后重新采集 FM，确认界面显示 `FM`、峰值频偏及解调曲线；
若仍为水平线，应保存波形并同时提供数据完整性面板中的丢样/连续性计数。
