## 3. 本轮确定的项目方向

沿用已讨论的 SMA 单信号射频带通采样方案。开发优先复用现有 Cyclone IV 工程与
AD9235-40 设计实例，同时保留 ADC12020 比较结果，禁止将它直接接入 40 MHz 时钟。
完整 AD9235 料号、封装、MODE 电平、实际接口和前端仍由 HW 核验。

```text
SMA 88–108 MHz 单个 AM/FM 信号
  -> 保护、射频预选滤波、差分驱动、ADC
  -> FPGA：12 bit 采集 -> NCO 混频 -> 方向校正/低通/抽取
           -> 舍入饱和 -> FIFO/帧封装 -> USB 桥接
  -> PC：协议解析 -> 有界队列 -> AM/FM/unknown/no_signal
         -> 测频、解调、重采样、声卡放音
         -> IQ 文件 + SQLite 记录、查询和分类
```

USB 3.0 仍是旧方案的设计目标，现有 FX2 USB 2.0 用作独立的链路原型。
若交付采用板载 FX2，需要明确批准架构变更并完成吞吐验证；若保留 USB 3.0，
则必须补充 SuperSpeed 桥接器、固件、原理图和主机驱动，不能只改端点或软件标签。
本轮不静默撤回已记录的 USB 3.0 决策。

上位机生产应用建议 Python + NumPy/SciPy + PySide6 + SQLite，USB/音频后端随
设备及平台确定；它们是待落实的技术栈建议，尚未增加依赖。本轮验证对话框用
Python 标准库 Tkinter，服务于工程检查，不代替接收机主界面或实时放音。

## 4. 采样与接口方案的门槛

固定 40 MS/s 的实数折叠边界为 `k*20 MHz`，100 MHz 正处边界，完整 AM/FM 边带
会折叠重叠。固定 10 MS/s 则在 90/95/100/105 MHz 有边界。两者均不能直接宣称
覆盖任意 88–108 MHz 中心频率。提高至 40 MS/s 不自动解决该问题。

下一步为 W-003 建立参数化带通采样模型，先验证 32/40 MS/s 两档候选。
32 MS/s 的边界是 `k*16 MHz`，两档在当前 RF 范围内有互补位置；这是数学候选，
不是已实现的动态 PLL 或合法时钟性能承诺。每档必须检查完整占用频带、保护带、
镜像干扰、输入滤波、采样时钟质量、ADC 高输入频率动态性能及板级捕获时序。
不合法配置应拒绝，并说明换档或输入条件要求。

已知粗略 RF 范围时，检查 `f_RF = m*Fs + s*f_alias` 的映射及方向。
未知 RF 需要多采样率等独立信息消歧，允许“中心频率未确定”；不能读取
`metadata.truth` 判别，也不能把 FFT 别名或用户设定频率作为实测中心。

计划接口如下，冻结前各实现均须参数化：

| 位置 | 速率/格式 | 处理及限制 |
| --- | --- | --- |
| ADC | 当前 PLL 配置 40 MS/s；12 bit 单通道原始码 | 依据完整 ADC 料号/MODE 转成 -2048…2047 的有符号整数 |
| 混频输出 | 与 ADC 同率；I、Q 各 24 bit / 11 位小数 | `I=x*cos`、`Q=-x*sin`，完整乘积；实数信号有 1/2 增益和混频镜像 |
| 抽取输出候选 | 500 kcomplex samples/s；I、Q 各 int16 | 40 MHz 档总抽取 80；32 MHz 档总抽取 64；逐级保证抗混叠，系数与缩位规则待验证 |
| 线上协议草案 | `IQS1`、小端、80 B 头、4096 complex samples/帧 | 沿用设计说明的草案；序号/索引/配置/CRC/缺口需共同测试后冻结 |
| 离线 JSON v1 | `normalized_float`，`I+jQ` | `sample_rate_hz` 是 IQ 速率；现有 48 kHz 合成样本不代表宽带 FM 验收 |
| 音频候选 | 48 kHz 单声道 | 有理重采样、时钟漂移和真实声卡连续放音待验证 |

上述 500 kS/s、16 bit、帧尺寸和音频速率是设计候选，不是课程正式指标。
以该帧草案算，IQ 负载 2,000,000 B/s，帧头约 9,765.625 B/s，总应用数据
约 2.010 MB/s；按 25% 余量需约 2.513 MB/s，仍须额外评估 USB 协议及调度开销。
40 MS/s 原始 12 bit 紧凑数据为 60 MB/s，16 bit 容器为 80 MB/s，不能假定板载
USB 2.0 可持续传输。链路必须优先传送 FPGA 滤波抽取后的 IQ。
FIFO 容量依据允许停顿和最大实际生产率计算，不任意写入资源/延迟数值。

ADC 参数核对来源：
[ADI AD9235 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9235.pdf)
列出 20/40/65 MSPS 等级、500 MHz 标称输入带宽和两种码型；
[TI ADC12020 产品资料](https://www.ti.com/product/ADC12020)
列出最高 20 MSPS 和 100 MHz 标称模拟带宽。
这些带宽值均不能替代 108 MHz 实测。
[Infineon FX2LP 器件资料](https://www.infineon.com/part/CY7C68013A-56PVXI)
确认 USB 2.0 HS；480 Mbit/s 是信号速率，非可保证的应用吞吐。

## 6. 验证对话框

启动入口：`python -B -m harness.dialog`。要求 Python 3.11+ 和 Tkinter/Tk。
Windows 常规 Python 安装可提供 Tk；本次环境为 Python 3.14.7 / Tk 9.0.4。

界面提供：任务多选、自动包含依赖、并发数设置、后台执行、取消、状态与耗时、
任务命令/写入范围详情、任务日志、历史摘要、打开运行目录及本方案阅读。
运行期间清单控件被禁用；关闭窗口时先取消子进程、保存结果并释放锁。
日志显示限制为尾部 128 KiB，原始日志完整保留。读取历史结果只接受项目
`.harness/` 下的摘要，不执行历史摘要中的命令。默认清单是项目自身受信内容。

运行数据仍保存到 `.harness/runs/<run>/`，取消退出码为 130，失败为 1，
配置/锁错误显示明确原因。界面不会清除外部遗留锁，不会自动安装驱动或仿真器。
