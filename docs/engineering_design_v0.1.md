```text

      |
     SMA
      |
输入保护、匹配 -> 射频预选/抗混叠滤波 -> 衰减/增益 -> 差分 ADC 驱动
                                                            |
                                   候选 ADC（12 bit）<- 可配置低抖动采样时钟
                                                            |
                            FPGA：并行采集 -> 按折叠频率数字下变频
                                          -> 滤波/抽取、频谱方向校正
                                            -> FIFO/帧封装
                                                    |
                                      USB 3.0 桥接控制器及固件
                                                    |
                                                 USB 3.0
                                                    |
                       上位机接收、解析、连续性检查、有界队列分发
                              |               |               |
                         FFT/参数测量    AM/FM 识别与解调    IQ 分块文件
                              |               |               |
                         SQL 结果管理    音频重采样         SQL 文件索引
                                              |
                                           声卡 DAC
                                              |
                                         扬声器/耳机
```

示波器只作为可选调试测量设备，不在正式采集链路中；这是本版对早期“接示波器”表述的设计假设。若同时观察 SMA 信号，应使用适当功分器、耦合器或探测方式并计入损耗，避免直接并接两个 50 ohm 端接而改变负载。

本版只设计接收功能，原先“射频收发单元”收敛为射频接收前端。频段内的 AM 可由信号源产生；常见中波 AM 广播不在 88–108 MHz 范围内。FM 广播先实现单声道音频，立体声和 RDS 为扩展项。

本版正式输入假设是 SMA 每次一个目标信号。普通天线可能同时接收多个电台，不自动满足该假设；若恢复天线接收需求，必须重新验证模拟预选和混叠分离能力。

## 3. 采样、带宽与速率预算

### 3.1 单信号带通采样与频率歧义

采样率按单个信号的完整占用频带及折叠位置选取，不再要求高于两倍射频载波。ADC 模拟输入仍为 88–108 MHz，射频驱动、输入带宽与采样抖动要求不能按低基带频率替代。SMA 不会滤掉噪声或信号源谐波，模拟前端仍须控制其他可折叠输入。

设信号有效支撑区间为 `[fL, fH]`，包含调制边带与频率不确定性，`B = fH-fL`。理想带通采样区间可按 `2*fH/n <= Fs <= 2*fL/(n-1)`（整数 `n >= 2`）分析，并在两端留保护带。`Fs > 2*B` 只是必要的速率条件，不能保证频谱不会重叠。

折叠边界为 `k*Fs/2`。整个目标信号必须避开边界，不能只检查载波。定义 `m = floor(f_RF/Fs + 0.5)`、`f_signed = f_RF - m*Fs`，折叠后正频率为 `f_alias = abs(f_signed)`；在通带不跨边界时，`s = sign(f_signed)` 表示频谱方向。对有效半带宽 `H` 和保护余量 `G`，要求 `H+G < f_alias < Fs/2-H-G`。

以下只作模型算例，不是已选定硬件时钟。20 MS/s 是 ADC12020 与 AD9235-20 的规格上限示例，不是所有 AD9235 等级的上限。实际设定计入时钟容差；19 MS/s 也须按具体器件检查允许范围和时钟电气条件。

| RF 中心/MHz | Fs/MS/s | m | f_signed/MHz | f_alias/MHz | 处理 |
| --- | --- | --- | --- | --- | --- |
| 88 | 20 | 4 | +8 | 8 | 不翻转 |
| 95 | 20 | 5 | -5 | 5 | 校正频谱翻转 |
| 100 | 20 | 5 | 0 | 0 | 折叠边界，拒绝该配置 |
| 100 | 19 | 5 | +5 | 5 | 可进入带宽/保护带检查 |
| 108 | 20 | 5 | +8 | 8 | 映射可行，模拟性能仍待验证 |

固定 20 MS/s 无法保证任意 88–108 MHz 信号都可恢复；19/20 MS/s 两档也尚未被批准为全范围方案。需对实际信号带宽、频差、滤波过渡带和时钟误差扫描验证，非法配置明确拒绝，不使用有损折叠后的信号伪造有效解调。

**单信号仍有 RF 频率歧义。** 20 MS/s 时，88、92 和 108 MHz 均可映射到 8 MHz。已知粗略 RF 范围时，可由该范围确定候选区间，再测残余频偏；粗调输入不是测量结果。未知中心频率时，需不同采样率的测量交集、可调预选或其他独立信息判别，不能只凭单次 FFT 回填 RF 频率。

本版建议先评估多采样率候选集合匹配：按测得的别名频率和误差枚举 `m*Fs ± f_alias` 中落在 88–108 MHz 的候选，用其他采样率的结果筛选。只有唯一候选且稳定性检查通过，才输出有效中心频率；无候选/多候选均报告未确定。采样间信号频率和调制统计需足够稳定，不满足时该方法不能保证识别。19/20 MS/s 是否足以消歧须单独验证，不能把算法待实现当成系统已满足测频要求。

FM 带宽可先用 Carson 估计 `B ≈ 2 * (频偏 + 最高调制频率)` 并结合实测。例如 ±75 kHz 频偏和 15 kHz 调制对应约 180 kHz，只是论证示例，不是已确认指标。立体声复合基带、频率失配和滤波过渡带需要额外预算。

现有离线样本的 48 kS/s 复数基带和 2 kHz FM 频偏是算法小样本，不能直接验证这里的宽带 FM，也不能与候选 48 kHz 音频采样率混为一谈。

### 3.3 传输与存储预算

下表使用十进制 MB/GB，以 19/20 MS/s 模型档位举例，常规持续传输对象为抽取后的 IQ。20 MS/s 的预算不是所有 AD9235 等级的最坏情况；若选更高实际速率，按 `Fs*12/8`（紧凑码）或 `Fs*2`（16 bit 容器）重新计算原始字节率和缓存，并重算抽取，不能直接沿用本表。

| 数据 | 计算 | 有效负载速率 |
| --- | --- | --- |
| ADC 原始 12 bit，20 MS/s 示例 | 20e6 * 12 | 240 Mbit/s，即 30 MB/s |
| ADC 原始 16 bit 容器，20 MS/s 示例 | 20e6 * 16 | 320 Mbit/s，即 40 MB/s |
| ADC 原始 12 bit，19 MS/s 示例 | 19e6 * 12 | 228 Mbit/s，即 28.5 MB/s |
| 单通道复数 IQ | 500e3 * (16 + 16) | 16 Mbit/s，即 2 MB/s |
| IQ 连续一小时 | 2e6 * 3600 | 7.2 GB，不含帧头和文件开销 |
| 单声道 16 bit PCM | 48000 * 16 | 0.768 Mbit/s，即 96 kB/s |

USB 3.0 SuperSpeed 的 5 Gbit/s 是链路信号速率，8b/10b 编码后的理论上限为 4 Gbit/s，应用负载还受 USB 协议、桥接总线、固件、驱动和主机影响。降低 ADC 速率后，原始流仍需独立验证，不能只凭链路标称值保证持续上传。常规模式保持传输 IQ；原始快照/流的码型、协议和缓存未定义，不混入现有 IQ 帧。

每帧暂用 4096 个复数样本、16384 B 负载和 80 B 帧头，应用帧开销约 0.49%，数据速率约 2.010 MB/s，帧积累时间约 8.192 ms。建议实测持续吞吐至少留 25% 余量，即不低于约 2.513 MB/s，并单独测试停顿恢复。这是项目建议门槛，不是课程正式指标。

缓存按 `容量 >= 数据产生速率 * 允许停顿时间` 估算。2 MB/s 下吸收 100 ms 停顿至少需约 200 kB 样本空间，另加实现余量。约 256 KiB 可作为评估起点，但必须先核对 BRAM、桥接缓存和主机队列；更长停顿需更大缓存或明确丢样，不能靠平均吞吐掩盖。

## 4. PCB 与硬件设计

### 4.1 核心板与扩展板

核心板暂以 Artix 系列为候选，承担 FPGA、配置存储、JTAG 及已有电源；DDR 仅在缓存确有需要且核心板支持时采用。具体型号、封装、速度等级和工具版本未确定。

扩展板建议包括 SMA、射频前端、ADC、采样时钟、USB 桥接控制器、USB 连接器、局部供电、按键/开关和指示灯。若核心板已有其中部分功能，应调整归属避免重复设计。本版不配置以太网 PHY/RJ45、发射功放或模拟混频本振。

采购核心板前必须确认 ADC 的 12 路并行数据、时钟及控制信号能接入连接器，核对 Bank 电压、输入阈值、时钟引脚、板间延迟和走线条件。不能只按逻辑单元数量选板。

### 4.2 射频、ADC 与时钟

| 模块 | 设计要求 | 主要检查 |
| --- | --- | --- |
| SMA 与保护 | 候选 50 ohm 接口，评估保护器件寄生和限幅 | 输入匹配、最大安全输入、插损 |
| 预选/抗混叠滤波 | 覆盖目标及边带，抑制可混叠信号和强带外干扰 | 通带、阻带、端点及边带响应 |
| 衰减/增益 | SMA 单信号测试防过载，按输入范围决定增益；天线模式不作为当前基线 | 噪声、压缩、互调、削顶 |
| ADC 驱动 | 单端至差分、共模、满量程依器件资料设计 | 失真、摆幅、共模、带宽 |
| ADC | AD9235 / ADC12020CIVYX/NOPB 按候选分别核对等级、封装、接口及射频性能 | 外部已知输入、幅频、SINAD、SFDR、108 MHz 端点 |
| 采样时钟 | 可配置低抖动时钟、适当分配与端接，切换时禁止输出有效数据 | 实际档位、占空比、稳定、频率误差、杂散 |

ADC12020 使用 12 bit 并行 CMOS/TTL 输出，不采用 LVDS 或 JESD204 接口，也不假定存在 ADC 输出数据时钟或内建测试码。依据输入采样时钟、数据输出延迟和 FPGA 建立保持要求选择捕获边沿/相位，并建模 PCB 延迟。数字码测试由外部已知输入或仿真注入提供，具体校准方式待电路确定。

AD9235 也按并行接口评估，但单独核对其控制引脚、码型、输出时序和驱动电源，不能直接复制 ADC12020 的捕获约束。最终两种采集适配方案均向 DDC 提供统一有符号样本语义；未选型前可建立参数化模型，不制造未经核实的器件时序值。

ADC12020 按 5 V 主供电及独立 `V_DR` 设计；AD9235 按标称 3 V 主供电及其输出驱动电源设计。各自的电压范围、启动条件和 FPGA Bank 兼容性须依手册核对，不可混用，更不能把 5 V 数据直接接入 Artix。参考电压、差分满量程和共模分别核对，SMA 信号不能未经驱动/匹配直接套用 ADC 满量程。

抖动限制可用 `SNR_jitter = -20*log10(2*pi*f_in*t_jitter)` 估算。100 MHz 输入、1 ps 总 RMS 抖动对应约 64 dB，尚未计入 ADC 自身噪声；应分配时钟与 ADC 孔径抖动预算，不能用标称位数替代有效性能。

### 4.3 USB 3.0 子系统

建议独立 USB 3.0 桥接/设备控制器，FPGA 通过并行 FIFO 或等效本地接口发送数据。FX3 类方案可作为候选类别，尚未核实或指定型号。普通 FPGA GPIO 不能直接连接 SuperSpeed 差分线，USB 协议栈也不是 Artix 默认自带功能。

选型同步确认本地总线位宽/时钟/握手、电平、Bulk 端点、控制接口、固件及启动存储、主机驱动、合法 VID/PID 使用方式和持续吞吐。FPGA 至桥接器的本地带宽需要单独验算。

数据面采用 Bulk IN，控制面用控制传输或独立命令端点完成识别、配置、启停和状态回读；端点地址待器件确定。固件负责 DMA、缓冲、错误统计和 USB 复位处理，不能只完成设备枚举。

连接器待机械及供电方案确定。若用 USB-C，需正确设计 CC、角色、电流声明及插头翻转下的 SuperSpeed 走线/切换，不能简单并联双面高速引脚。线缆和连接器均需支持实际 SuperSpeed 链路。

### 4.4 电源、布线和结构

- 分别估算 FPGA、ADC、驱动、时钟、USB 控制器和前端功耗及启动时序。USB 总线或独立供电待定，不假定一个 USB 口足够供电；独立供电需处理 VBUS 检测和防倒灌。
- 射频、ADC 和时钟区域远离开关电源与 USB 高速区；保持连续参考平面，避免机械分割地平面导致高速回流跨缝。
- USB SuperSpeed 差分阻抗通常以 90 ohm 为目标，ADC 并行单端数据按器件要求；最终线宽、间距和时序容差由板厂叠层和器件指南计算，不猜定。
- ADC 采样时钟与并行数据、USB 差分对和板间连接分别设置约束，检查过孔、支路、参考层切换及连接器损耗。
- 按键建议用于复位及启停，开关用途待定；指示灯区分电源、配置就绪、USB、采集中和错误。控制模块统一处理防抖及主机命令优先关系。
- 预留测试点时避免高速长支路，执行原理图 ERC、PCB DRC，并记录豁免依据。
- 外壳核对 SMA/USB 插拔空间、核心板叠高、安装孔、散热和测试可达性，打印后实装验证。

### 5.2 混频、滤波和定点

统一 `z[n] = I[n] + j*Q[n]`，正相位变化为正基带频率，与离线 IQ 契约一致。实数 ADC 输入采用：

```text
I_mix[n] =  x[n] * cos(phase[n])
Q_mix[n] = -x[n] * sin(phase[n])
phase[n+1] = phase[n] + 2*pi*f_NCO/Fs
```

NCO 使用目标 RF 的别名频率。正频率 DDC 后得到原始 I/Q，`s=+1` 时直接使用，`s=-1` 时在宽位宽域取共轭，再舍入/饱和，避免 int16 最小负数取负溢出。选择不跨折叠边界的整数 `m` 和方向 `s`，定义实际数字调谐对应的 `f_tuning = m*Fs + s*f_NCO`；校正后的频偏为 `f_RF - f_tuning`。不能将低速 NCO 值本身当作射频中心频率。

实数余弦混频的目标分量含 1/2 幅度因子，须纳入增益预算。I/Q 顺序、校正方向和缩放改变时同步模型与主机；频率区间未确定时不能把候选方向当成有效结果。

可先评估 32 bit 相位累加器，20 MS/s 示例的步进约 `Fs/2^32 = 0.00466 Hz`。这只是数字调谐分辨率，实际 RF 精度受折叠区间判别、时钟误差、校准及估计算法限制；RF 误差预算仍需考虑约 100 MHz 输入，不能按小的别名频率低估时钟影响。

若保持 500 kS/s IQ，20 MS/s 示例总抽取倍数为 40，19 MS/s 示例为 38；任意时钟不一定能用整数抽取得到相同输出率，需要约束档位或设计有理重采样。各档分别确定多级结构、通阻带、纹波、抑制度、位宽和滤波配置 ID，可比较 CIC、补偿 FIR 和多相 FIR，不能只验证倍率乘积。

CIC 的通带下垂、有限阻带和增长位宽需计算；每级抽取前抑制会折叠入最终有效通带的分量，末级滤波无法消除已经产生的混叠。滤波系数尚未确定。

ADC12020 输出为 12 bit offset binary：整数意义上 `signed_sample = unsigned_code - 2048`，范围为 -2048 至 2047；可翻转最高位后按有符号补码解释。AD9235 的实际码型在完整型号和配置明确后记录：若为 offset binary 则用相同转换；若为补码则直接有符号解释，不能重复偏移。两者在进入 DDC 前统一有符号语义，扩位明确符号扩展。乘法/累加器按最坏情况定宽，每个缩位点记录移位、舍入和饱和；USB I/Q 各 16 bit 是处理后容器，不表示 ADC 精度提高。

并行 ADC 按每个采样周期一个 12 bit 样本设计，DSP 时钟与流水线由资源/时序评估决定。不同采样档位均需独立检查时序约束、NCO 步进、抽取系数及样本索引，不继续沿用高速解串接口假设。性能以综合、实现时序及上板为准。

### 5.3 时钟域、反压和异常

采集域、DSP 域、USB 本地接口域依实际设计划分，多位数据跨域采用异步 FIFO 或握手，控制信号采用适当同步。流接口明确 `valid/ready`，停顿期间保持数据与控制稳定。

ADC 连续采样，不能因 USB 反压假定输入暂停。建议以完整 IQ 帧管理缓存，空间不足时丢弃新产生的完整帧，继续推进样本索引和生产序号并增加丢样计数；下一可交付帧报告间断/溢出。不能拼接部分新旧帧，桥接侧仅在确认有空间后接收数据。

时钟失锁、ADC 失步或严重采集错误时停止输出有效样本并保留状态，恢复后重新校准及建立新流。调谐、采样配置变化和重启也建立新 `stream_id`，滤波过渡期结束后再发送有效数据。

采样时钟切换顺序为停止旧流、修改时钟、确认稳定、复位/清空旧配置流水线和 FIFO、加载新 NCO/滤波/方向配置、回读后启动新流。时钟确认方式及等待时间依器件资料和实测确定。没有 ADC 内建锁定/错误指示的状态不得虚构为已检测，需说明由时钟芯片、FPGA 监测或软件判断的来源。

## 6. USB 应用协议草案

本节为待 FPGA/HOST 联合评审的线上协议提案，尚未实现。现有 `docs/iq_contract.md` 离线 JSON v1 不变。USB Bulk 读取边界不是应用帧边界，主机必须处理分片、合并和残留数据。

### 6.1 帧布局建议

固定 80 B 帧头，随后为 IQ 负载；多字节整数及浮点值采用小端，浮点采用 IEEE 754 binary64。负载为 `I0,Q0,I1,Q1,...`，每分量 `int16`，每复数样本 4 B。

| 偏移/B | 长度/B | 字段 | 语义 |
| --- | --- | --- | --- |
| 0 | 4 | magic | ASCII `IQS1` |
| 4 | 2 | version | 本草案为 1 |
| 6 | 2 | header_bytes | 本草案固定 80 |
| 8 | 4 | payload_bytes | 等于 `sample_count * 4` |
| 12 | 4 | flags | 间断、FIFO 溢出、削顶等，位定义待冻结 |
| 16 | 8 | stream_id | 主机分配，会话内不重复；新流重新开始索引 |
| 24 | 8 | sequence | 从 0 起的生产帧序号，被丢弃帧同样消耗序号 |
| 32 | 8 | first_sample_index | 首个样本的流内计划输出索引，丢样仍推进 |
| 40 | 8 | sample_rate_hz | 正有限 binary64，复数基带采样率，标称/校准来源另存配置 |
| 48 | 8 | tuning_center_hz | 有限 binary64，已确定折叠区间下的 RF 调谐中心，不是别名频率或测量结果 |
| 56 | 4 | config_id | 与该流不可变配置记录关联 |
| 60 | 2 | sample_format | 候选编码 1 表示归一化有符号 16 bit I/Q |
| 62 | 2 | channel_count | 本版固定 1 |
| 64 | 4 | sample_count | 正常 4096，停止时可发送非零短帧 |
| 68 | 4 | reserved | 置 0 |
| 72 | 4 | header_crc32 | 覆盖帧头字节 0–71 |
| 76 | 4 | payload_crc32 | 覆盖完整 IQ 负载 |

CRC 建议使用 CRC-32/ISO-HDLC，反射多项式 0xEDB88320，初值和最终异或均为 0xFFFFFFFF，`123456789` 检验值为 0xCBF43926。USB 已有链路检错，应用 CRC 用于封装、保存和回放检查；实现前冻结共用测试向量。

接收端限制最大 4096 个复数样本，先检查头部和长度，再接收/分配负载；拒绝未知版本、格式、非有限或非法数值。CRC 错误、帧序号或样本索引不连续均产生可见事件，重新同步不伪造连续数据。

16 bit 分量转离线浮点时采用 `value / 32768`，范围为 `[-1, 1)`，仅为数字归一化幅度；电压/功率解释需要模拟增益、满量程和校准信息。离线 JSON v1 只导出连续片段，不能把有缺口样本直接拼成一个 capture。

### 6.2 控制与生命周期

建议命令为 `GET_INFO`、`GET_STATUS`、`SET_CONFIG`、`START`、`STOP`，请求标识和明确应答用于确认执行结果。实际 NCO 频率、采样率、滤波、缩放、固件版本和错误计数可回读；本版不冻结端点地址和寄存器位定义。

控制面和持久化配置补充 ADC 完整型号/速率等级、输入码型、实际/标称 ADC 时钟及来源、RF 搜索范围、折叠整数 `m`、方向 `s`、别名 NCO、方向已校正标记、频率候选/确定状态和滤波配置 ID。80 B 帧布局与离线 JSON v1 不变；`sample_rate_hz` 仍是 IQ 速率，`tuning_center_hz` 仍是 RF 调谐中心。主机不得二次取共轭。未知 RF 的探测阶段数据另作待定分析，正式连续 IQ/JSON 输出前必须有明确 RF 映射；原始实数探测数据协议另行定义，不伪装成已确定 RF 的 IQ 帧。

先保存配置再启动采集；配置变化先结束旧流，新配置生效后建立新流。主机保存启动 UTC 时间和单调时钟参考，样本索引用于相对采集时间，不能把 USB 到达时间当作精确采样时刻。新流索引零点为滤波稳定后的首个计划有效样本。

USB 断连时结束当前流、取消传输并记录原因；重连重新核对设备和配置。检测实际协商速度，本版要求 SuperSpeed，降为 USB 2.0 默认拒绝启动并提示；后续如支持降级，需独立预算和验证。

## 7. 上位机设计

### 7.1 模块与技术栈候选

首版可评估 Python + NumPy/SciPy 算法、Qt/PySide 界面、SQLite 本地 SQL、USB 库或厂商 SDK 异步传输和成熟音频库。它们是候选依赖，尚未安装或写入项目；确认主机系统、驱动、许可证、分发和性能后再确定。现有标准库 harness 不因此增加依赖，PyTorch 不是必需条件。

| 模块 | 职责 |
| --- | --- |
| 设备接入 | 枚举、版本检查、配置、异步接收、取消及重连 |
| 协议解析 | 分片缓存、CRC/字段校验、流与缺口识别、I/Q 转换 |
| 数据分发 | 有界队列、DSP/记录/显示分发、水位和延迟统计 |
| 信号处理 | 通道滤波、FFT/PSD、识别、测频、解调和重采样 |
| 音频 | 回调、音量、静音、缓冲和时钟漂移控制 |
| 记录管理 | IQ 文件、SQL 事务、查询、分类、回放及导出 |
| 界面 | 设备状态、调谐、频谱、结果、录制和历史记录 |

USB、磁盘、DSP 和界面刷新分开调度，不能相互无限阻塞。音频回调避免访问数据库、磁盘和耗时计算，信号按块处理，不在 Python 层逐样本循环处理高速流。

### 7.2 FFT、中心频率与识别

FFT 使用窗函数、幅度归一化和可选平均，显示当前接收通道频谱。bin 间隔 `Fs_IQ/N` 不等于测量准确度。全频段同时显示/扫频属于扩展，不能把单通道频谱标成完整 88–108 MHz 实时频谱。

仅在折叠区间已确定且 FPGA 完成方向校正后，中心频率采用 `f_center_est = f_tuning + f_offset_est`。载波明显的 AM 可评估峰值插值或载波跟踪；FM 可结合占用频带中心、鉴频均值及观测条件估计。不能把最大 FFT 峰或用户粗调值直接当作 RF 测量结果。未消除歧义时报告未确定并保留候选，不强制生成有效 RF 数值；测量记录包含方法、输入先验、观察时长、有效性及校准信息。

先判断有无有效信号、削顶和带宽，再根据包络变化、瞬时频率变化及谱特征识别，允许 `AM`、`FM`、`unknown`、`no_signal`。低信噪比、未调制载波及混合信号可能无法可靠区分；保留不确定状态，不能读取样本真值标签完成判别。

### 7.3 解调与放音

- AM：常规带载波 AM 采用包络检测、去直流、音频低通和电平控制；抑制载波 AM、SSB 不在首版保证范围。
- FM：可用 `arg(z[n]*conj(z[n-1])) * Fs_IQ/(2*pi)` 鉴频，频偏加残余频差必须满足相位差不混叠条件；低幅度和无信号时抑制异常音频。
- 广播 FM 去加重常数依接收标准选择并保存，不能对所有信号无条件使用同一常数。单声道输出需滤除无用复合基带分量。
- 500 kS/s 至 48 kHz 可用分阶段或有理重采样，总比例 12/125，满足抗混叠；AM/FM 各自设置合适音频带宽。
- ADC 和声卡时钟独立，会造成长期缓冲漂移，应根据水位反馈做小幅自适应重采样或其他经验证的速率匹配，不能只设置相同名义采样率。
- 丢样、重调谐或无信号时重置相关滤波/鉴频状态，静音或淡入淡出，并保留事件，不能跨缺口按相邻样本鉴频。

数字音频交给电脑声卡 DAC 转为模拟信号，由扬声器、耳机或有源音箱输出。麦克风是输入器件；扩展板本版无需额外音频 DAC。

### 7.4 IQ 文件与 SQL 记录

采用“按块保存 IQ 二进制文件 + SQLite 元数据及索引”，保留 SQL 需求，但不逐样本写 SQL 行，以减少事务开销和存储放大。波形文件可保存带版本、索引和 CRC 的应用帧，另存完整配置，并支持离线回放。

| 逻辑表 | 建议字段内容 |
| --- | --- |
| captures | 采集 ID、UTC 起止时间、设备/固件/软件版本、结束原因 |
| stream_configs | 流标识、ADC 型号、ADC/IQ 速率、RF 调谐、折叠区间/方向、NCO、先验/确定状态、滤波、位宽、缩放、增益、校准 |
| segments | 文件位置、字节偏移、起止样本索引、样本数、连续性与校验 |
| measurements | 流及样本区间、中心频率及单位、调制类型、有效性、算法版本 |
| events | 断连、丢样、FIFO 溢出、削顶、磁盘异常及对应索引/时间 |

按时间、中心频率、调制类型检索分类，支持测量结果和音频导出。SQL 使用参数化查询，旧记录保留原配置；实际表结构、外键、索引和迁移版本待实现时定义。

按大小或时间切文件，写入成功后提交对应索引，关闭时执行必要持久化；崩溃恢复检查未完成片段和数据库/文件一致性。录制前检查空间并配置保留策略，默认不自动删除历史数据。

显示队列满可丢过时刷新；DSP 为恢复实时性丢积压数据时需报告缺口并重置状态；录制队列或磁盘异常时停止该次录制并记录原因，不能静默丢块仍称完整波形。严格无丢样模式中，任一丢样应使该次采集失败。

## 9. 实施顺序与未决事项

1. 确认预算、可用仪器、输入电平和 AM/FM 测试范围，评审候选参数。
2. 比较 AD9235 完整料号与 ADC12020CIVYX/NOPB 的报价和 RF 性能，再联合选择 ADC、Artix 核心板、时钟及 USB 桥接器，核对供电/时序。

4. 用模拟数据贯通 FPGA 封装、USB 固件、主机接收及回放，再接 ADC/DDC，各阶段独立留证。

## 10. 后续 Harness 工作入口

后续对话先读取本方案、`docs/work_plan.md`、`docs/iq_contract.md` 和 `harness/tasks.json`。AD9235 与 ADC12020CIVYX/NOPB 均为候选，W-009 未完成，W-005 需分别核对接口时序。模型的器件身份、速率等级/上限、实际时钟和码型应参数化，不能把 ADC12020 当唯一硬件。现有 JSON 描述连续归一化基带 IQ，不是原始 RF 数据，不静默修改该契约。

建议优先补充以下真实模型/测试，完成后再按已有工作包和 writes 规则注册 harness；本次未新增可执行检查，也未运行硬件验证：

1. 参数化 RF 合成与带通采样，检查完整边带、保护带及候选器件/等级的时钟上限。19/20 MS/s 仅为样例；ADC12020 和 AD9235-20 拒绝超过 20 MS/s，AD9235-40/-65 按对应等级独立校验，不全局禁止或允许 24/25 MS/s。最低频率/占空比等未核实参数标待定。
2. 同别名不同 RF 的歧义用例、多采样率匹配、频率不稳定及不能唯一判定的错误路径；频率识别不得读取样本真值标签。
3. 上下折叠方向、正负频偏、AM/FM 解调极性与 RF 元数据；覆盖折叠到直流/Nyquist 附近必须拒绝的情况。
4. ADC12020 的 12 bit offset binary 0/2047/2048/4095 边界，以及 AD9235 最终码型配置对应转换；共同检查符号扩展、共轭、饱和和按实际档位的抽取/重采样，不把未确认 AD9235 码型写成器件事实。
5. 时钟切换的新流/配置同步、USB 反压/缺口和上位机回放，实际 RTL/USB 入口就绪后再注册对应检查。

离线模型只能验证数学和接口逻辑，不能证明任一候选在 108 MHz 的实际性能，也不能替代时钟、PCB 和实时音频验证。正式验收指标仍待确认。
