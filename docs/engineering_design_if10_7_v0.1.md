## 1. 文档定位与需求边界

本文依据项目 README、项目规范和方案讨论编写，作为 [射频直接采样方案](engineering_design_v0.1.md) 的独立备选，供器件、成本和实现难度比较。新增本文不表示已决定替换直采基线，也不代表完成选型或实现。课程要求仍以原始任务书为准；本文沿用 README 的需求整理，未重新核读原始 `.doc`。

本方案覆盖 PCB、FPGA、USB 固件和上位机，保留核心板加扩展板、USB 3.0、SQL 记录管理和电脑声卡放音。模拟变频只搬移频谱，AM/FM 识别与解调仍在上位机，FPGA 仍承担采集、数字下变频及滤波抽取。

| 状态 | 内容 |
| --- | --- |
| 任务要求 | 88–108 MHz 输入；AM/FM 识别解调与实时放音；中心频率等测量及结果管理；电路、PCB、结构交付 |
| 本备选指定的方向 | 模拟变频至 10.7 MHz，单路实数 ADC，中频数字下变频，USB 3.0 |

| 待定项 | 器件、输入电平、通带/阻带指标、预算、电源、主机系统、工具版本及正式验收阈值 |

接收频段内的 AM 可用信号源产生，常见中波 AM 广播不在本方案频段内。首版 FM 放音以单声道为目标，立体声和 RDS 为扩展项。射频模块只需接收功能，暂无发射链路。

## 2. 总体架构

```text
SMA / 天线
    -> 输入保护、匹配
    -> 射频预选滤波、可控衰减/必要的低噪声增益
    -> 模拟混频器 <--- PLL 本振、缓冲与本振滤波
    -> 10.7 MHz 中频带通滤波
    -> 中频增益、ADC 驱动及必要的附加抗混叠滤波
    -> ADC <--- 低抖动采样时钟
    -> FPGA：采集 -> 10.7 MHz 数字混频 -> 低通/抽取
             -> 频谱方向校正 -> 定点缩放 -> FIFO/帧封装
    -> USB 3.0 桥接器及固件
    -> 上位机：接收、连续性检查、有界队列
         -> FFT、识别、测频
         -> AM/FM 解调、重采样、声卡 DAC、扬声器/耳机
         -> IQ 文件、SQL 记录与索引、查询和回放

上位机控制 -> USB -> FPGA 控制寄存器 -> 本振、增益及采集配置
```

示波器作为调试设备，不作为 ADC 或正式数据链路。观察射频输入时要计入功分/耦合损耗和探头负载，不能直接并接两个 50 ohm 端接。

本方案先在模拟域选取一个目标通道附近的中频窗口，再在 FPGA 精细滤波。因此不能承诺同时显示整个 88–108 MHz 频段；扫频需要分步调谐，并包含 PLL、模拟滤波和数字滤波的稳定时间。

## 3. 频率规划与镜像分析

### 3.1 本振与中频

单个实数混频器产生和频与差频。中频滤波器保留 `f_IF = abs(f_RF - f_LO)` 附近的目标分量，抑制和频、本振泄漏及其他产物。本版使用高侧本振作为候选：

```text
f_IF_nominal = 10.7 MHz
f_LO = f_RF_target + 10.7 MHz
f_LO_range = 98.7 ... 118.7 MHz
f_image = f_LO + 10.7 MHz = f_RF_target + 21.4 MHz
```

| 目标射频/MHz | 高侧本振/MHz | 目标中频/MHz | 射频镜像/MHz |
| --- | --- | --- | --- |
| 88.0 | 98.7 | 10.7 | 109.4 |
| 100.0 | 110.7 | 10.7 | 121.4 |
| 108.0 | 118.7 | 10.7 | 129.4 |

高侧本振使镜像集中在 109.4–129.4 MHz，便于先按同一注入方向设计；不代表它在所有器件或干扰环境下最优。低侧方案的本振为 77.3–97.3 MHz，镜像为 66.6–86.6 MHz，同样需要独立的预选滤波论证。首版不自动切换注入方向，避免未定义的频谱方向和配置状态。

### 3.2 射频镜像抑制

100 MHz 与 121.4 MHz 经 110.7 MHz 实数本振都可变成 10.7 MHz。进入同一中频带宽后，单路实数接收无法再区分来源；中频滤波和 FPGA 滤波不能补救射频镜像。因此预选滤波必须位于混频前。

最接近目标频段的高侧镜像中心为 109.4 MHz，与 108 MHz 的名义边界仅相隔 1.4 MHz；考虑载波边带、频率误差及干扰带宽后，实际滤波过渡余量更小。不能假定一个宽通带 88–108 MHz 滤波器自然有足够镜像抑制。需要根据实测/模型选择足够阶数的预选器，必要时评估跟踪或分段滤波；若成本无法满足，应重新评审频率规划，而非降低验收要求。

镜像抑制度应从最大镜像干扰与最弱目标信号推导。例如目标 -80 dBm、镜像 -30 dBm，要求镜像产物至少低于目标 20 dB，所需相对抑制约为 70 dB，另需考虑转换增益差异和余量。这只是预算示例，不是本项目已定灵敏度或抑制度。

射频预选还需限制混频器前的强带外能量；强干扰造成压缩或互调后，后级滤波无法恢复。LNA 的位置和增益应结合噪声与线性度共同决定。

### 3.3 高侧注入的频谱翻转

高侧本振下，射频频率升高会使中频频率降低。设目标调谐频率为 `f_tune = f_LO - f_NCO`，其中 `f_NCO` 约为 10.7 MHz，则：

```text
f_RF = f_tune + delta
f_IF = f_LO - f_RF = f_NCO - delta
未经校正的数字下变频结果：f_baseband_raw = -delta
```

建议 FPGA 在低通/抽取后对复数结果取共轭，即 `I_out = I_raw`、`Q_out = -Q_raw`，恢复“正基带频率表示高于调谐中心的射频频率”的统一约定。取负在宽位宽域完成，再舍入/饱和，避免直接对最小 int16 值取负导致溢出。

校正后上位机继续使用 `f_RF_est = f_tune + f_baseband_est`。例如目标调谐 100 MHz、实际信号 100.020 MHz，本振 110.7 MHz：模拟中频 10.680 MHz，原始 DDC 频偏 -20 kHz，校正后为 +20 kHz，最后得到 100.020 MHz。遗漏校正会反转频谱、测频方向和 FM 鉴频极性；主机也不能重复校正。

这里忽略的固定相位/增益由参考模型和校准处理。本振与采样时钟的实际误差会进入测量预算，PLL 的锁定指示本身不能证明频率准确。

## 4. 中频滤波、采样与吞吐

### 4.1 候选参数

| 参数 | 候选值 | 说明 |
| --- | --- | --- |
| 中频中心 | 10.7 MHz | 本备选固定的名义中频 |
| 中频通带 | 初步评估 10.7 MHz ±150 kHz | 约 300 kHz 总宽，仅作选型起点；有效通带需按纹波和群时延定义 |
| ADC | 40 MS/s，12–14 bit，单路实数 | 具体型号和 CMOS/LVDS 等接口待定 |
| FPGA 数字 NCO | 约 10.7 MHz，可微调 | 量化误差和调谐偏差保存到配置 |
| 抽取后 IQ | 500 kS/s，I/Q 各 16 bit | 总抽取倍数 80 |
| 数字有效通带 | 先评估约 ±100 kHz | 需结合信号频偏、带宽和邻道指标验证 |
| 音频 | 48 kHz，单声道 | 与 ADC/IQ 采样率明确区分 |

FM 带宽可用 Carson 估计 `B ≈ 2 * (频偏 + 最高调制频率)`。±75 kHz 频偏、15 kHz 调制对应约 180 kHz，是论证示例；若保留立体声复合基带，需重新预算。中频滤波器不能只看 10.7 MHz 标称中心或 3 dB 带宽，还需检查有效通带、群时延、插损、端接阻抗、温漂和批次误差。窄带通信滤波器可能破坏宽带 FM。

若使用固定较宽中频通带兼容 AM/FM，AM 的窄带选择性主要由后续数字滤波提供，但 ADC 和前端仍会承受模拟通带内的邻道干扰。不可把数字窄带处理等同于提高前端抗过载能力。

### 4.2 抗混叠与采样条件

40 MS/s 的第一奈奎斯特区为 0–20 MHz，10.7 MHz 中频及候选通带位于其中，不依赖欠采样。对上沿 10.85 MHz，理想最低采样率为大于 21.7 MS/s，实际还需过渡带；选 40 MS/s 仅为预算起点。

ADC 前仍必须滤波：40 MS/s 下 29.3 MHz 会折叠到 10.7 MHz，29.15–29.45 MHz 可折叠到候选中频通带。应同时评估其他 `k*Fs ± f_IF` 混叠频段、混频和频、本振泄漏及放大器谐波。中频带通滤波和必要附加低通的组合须在 ADC 输入端验证。

射频镜像与 ADC 混叠是两个不同问题：前者在混频前通过射频预选处理，后者在采样前通过中频/抗混叠滤波处理，两者不能相互替代。

抖动限制为 `SNR_jitter = -20*log10(2*pi*f_in*t_jitter)`。10.7 MHz、1 ps 总 RMS 抖动对应约 83.45 dB，优于在 100 MHz 输入时的同抖动约 64 dB，但系统新增了本振相位噪声、互易混频和转换损耗。不能由 ADC 抖动改善推断整机 SNR 一定改善。

### 4.3 数据与缓存预算

以下使用十进制 MB/GB，常规模式发送抽取后的 IQ。

| 数据 | 计算 | 有效负载 |
| --- | --- | --- |
| 12 bit 原始中频 | 40e6 * 12 | 480 Mbit/s，即 60 MB/s |
| 14 bit 原始中频 | 40e6 * 14 | 560 Mbit/s，即 70 MB/s |
| 16 bit 容器原始中频 | 40e6 * 16 | 640 Mbit/s，即 80 MB/s |
| 复数 IQ | 500e3 * 32 | 16 Mbit/s，即 2 MB/s |
| IQ 一小时 | 2e6 * 3600 | 7.2 GB，不含文件和帧头 |
| 16 bit 单声道 PCM | 48000 * 16 | 96 kB/s |

沿用候选 4096 个复数样本/帧及 80 B 帧头：应用数据约 2.010 MB/s，帧积累 8.192 ms；建议持续吞吐测试至少留 25% 余量，即约 2.513 MB/s，同时覆盖 USB 停顿和磁盘写入压力。

USB 3.0 的 5 Gbit/s 不是可直接使用的应用带宽。原始中频数据虽显著降低，能否持续上传仍由桥接本地总线、固件、驱动和主机实测决定；本版仅保证设计目标为 IQ 模式，原始快照/流需另外定义协议和验证。

IQ 端 100 ms 停顿需约 200 kB 样本空间，可按约 256 KiB 加协议和水位约束评估；实际容量核对 BRAM、桥接缓存和主机队列后确定。低 ADC 采样率不会降低相同 IQ 输出配置下的 USB 负载或保存容量。

## 5. PCB 与硬件设计

### 5.1 核心板和扩展板分工

Artix 系列核心板为候选，承担 FPGA、配置/JTAG 及已有电源；不能在未检查核心板原理图和引出引脚前确定型号。40 MS/s 中频接口通常比 250 MS/s 射频直采容易实现，但仍须核对实际 ADC 电平、时序、Bank、时钟能力及资源。

扩展板建议包含 SMA、保护与预选、可控衰减/增益、混频器、PLL 本振及缓冲、中频滤波/放大、ADC 驱动、ADC 与采样时钟、USB 3.0 桥接器、按键/开关/指示灯和局部供电。按核心板已有功能避免重复设计。外部 DDR 仅在缓存需求证明必要时采用。

### 5.2 选型与模拟链路预算

| 模块 | 关键依据 |
| --- | --- |
| 射频保护/预选 | 50 ohm 匹配、器件寄生、端点及边带通过、109.4–129.4 MHz 镜像抑制、强干扰 |
| 增益/衰减 | 最弱信号、最大输入、噪声系数、压缩点和互调；避免强信号先压缩再衰减 |
| 混频器 | RF/LO/IF 端口范围、转换增益/损耗、噪声、IIP3/P1dB、LO 驱动电平与隔离 |
| 本振/PLL | 98.7–118.7 MHz 连续覆盖、步进、参考误差、相位噪声、杂散、锁定时间和驱动 |
| 中频滤波 | 10.7 MHz 有效带宽、插损、纹波、群时延、阻抗及镜像之外的混频产物抑制 |
| 中频增益/ADC 驱动 | 共模、差分幅度、输入阻抗、线性度、满量程和过载恢复 |
| ADC | 40 MS/s 候选、10.7 MHz 输入 SINAD/SFDR、码型、接口、电源和驱动需求 |
| 时钟与参考 | ADC 抖动、PLL 参考噪声、绝对频率误差、分配隔离和校准 |

先按最弱信号和最强干扰分别画电平预算，逐级计入滤波插损、混频损耗及增益。总噪声系数可用线性单位的 Friis 公式估算：`F_total = F1 + (F2-1)/G1 + ...`，并独立评估各级压缩及三阶互调。全部数值须来自器件资料和输入条件，尚不能承诺灵敏度。

中频增益可以采用手动控制或慢速 AGC。过快 AGC 会改变 AM 包络及识别特征，必须记录增益及算法；首版建议先固定/手动增益验证，再增加有时间常数依据的 AGC。中频增益不能补救混频器之前的压缩。

### 5.3 本振与参考时钟

本振应由可配置频率合成器和合适缓冲提供，LO 驱动电平依混频器资料确定，不使用未经波形、抖动和杂散论证的 FPGA 普通 GPIO 直接充当射频本振。合成器 SPI 等控制接口、电平、锁定信号和启动顺序均需明确。

可评估 PLL 与 ADC 共用稳定参考以便校准，但不因此认为两路噪声或误差自动抵消。PCB 上分别处理参考分配、终端和电源隔离，分析相位噪声对邻近强信号造成的互易混频。

98.7–118.7 MHz 本振有一部分落在接收频段内，需检查 LO 到 RF/天线泄漏、空间耦合和屏蔽。扫描全频段检查谐波与 `m*f_RF ± n*f_LO` 杂散落入中频的组合；单一频点工作正常不足以证明整个调谐范围可用。

### 5.4 布局、电源、USB 与结构

- 按 RF 输入、混频/本振、中频/ADC、FPGA、USB 和电源分区布局，缩短敏感路径；通过位置、屏蔽与回流控制隔离，避免割地导致高速信号跨缝。
- PLL 环路滤波和模拟电源远离开关节点、FPGA 与 USB 活动区，依据器件指南去耦；计入新增 PLL、缓冲、混频和中频放大功耗。
- 中频滤波器按规定源/负载阻抗端接，不能把全部器件默认当成 50 ohm；ADC 差分共模与驱动依资料设计。
- USB 使用独立 SuperSpeed 桥接控制器，经并行 FIFO 或等效本地接口接 FPGA；FX3 类仅为候选，实际芯片、固件、SDK/驱动和合法 VID/PID 待确认。
- USB 采用 Bulk IN 数据面和控制命令面；普通 FPGA GPIO 不直接连接 SuperSpeed 线。USB-C 若选用，需 CC、角色和翻转处理；供电及 VBUS 防倒灌单独设计。
- USB 差分通常以 90 ohm 为目标，其余线按器件接口要求，实际线宽、间距、叠层及约束由板厂参数计算。ADC 时钟/数据的时序约束有原理图和数据手册依据。
- 按键用于复位/启停等明确功能，FPGA 统一防抖和命令优先关系；显示电源、PLL 锁定、采集、USB 和错误状态。
- 设置 RF/LO/IF 及电源的适当测试入口，避免长支路和测量负载破坏链路；示波器不能替代滤波器频响/杂散所需的测量条件。
- 完成 ERC/DRC、BOM 及制造资料；核对 SMA/USB、屏蔽罩、核心板高度、孔位和散热，3D 打印后实装验证。

## 6. FPGA 与控制固件设计

### 6.1 数据处理模块

| 模块 | 输入与输出/职责 |
| --- | --- |
| 时钟/复位 | 各域同步释放复位，监控采样时钟、ADC 与 PLL 状态 |
| ADC 接收 | 实数中频数据，测试码校准、字对齐、码型转换及削顶统计 |
| 数字 NCO/混频 | 约 10.7 MHz 数字本振，实数转复数，保持控制与数据对齐 |
| 低通与多级抽取 | 候选 40 MS/s 到 500 kS/s，总倍数 80 |
| 频谱方向校正 | 高侧注入取共轭，向主机提供统一 RF 正频方向 |
| 定点缩放 | 增益预算、最近偶数舍入、有符号饱和和统计 |
| FIFO/帧封装 | 序号、索引、状态和 CRC，处理 USB 反压 |
| USB 本地接口 | 跨域握手、桥接总线时序、DMA/缓冲配合 |
| 控制模块 | SPI 本振/ADC/增益配置，锁定检查、状态、启停及错误处理 |

未校正的 DDC 采用 `I_raw = LPF(x*cos(phi))`、`Q_raw = LPF(-x*sin(phi))`，相位每个 ADC 样本递增 `2*pi*f_NCO/Fs`。完成低通和抽取后，高侧模式输出 `I_raw - j*Q_raw`。最终仍采用 `z = I + j*Q`，与现有离线 IQ 契约一致。

可先评估 32 bit NCO，40 MS/s 下步进约 0.00931 Hz。这不等于绝对测频精度。乘法、滤波、共轭和缩位均使用明确有符号格式；混频 1/2 幅度因子、模拟转换增益及数字滤波增益分别记录，不把任意归一化值当成射频功率。

抽取可比较 `4 * 4 * 5 = 80` 等多级组合（40 -> 10 -> 2.5 -> 0.5 MS/s），仅为结构候选，不是已设计好的滤波器。每级抽取前需抑制会折叠入有效通带的分量，包括实数混频的共轭频谱副本；各级通阻带、纹波、位宽和延迟经模型确定。CIC 如采用，还需评估下垂、阻带和补偿 FIR。

### 6.2 调谐状态机

建议状态为 `IDLE -> CONFIGURE -> WAIT_LOCK -> SETTLE -> STREAMING`，错误进入 `ERROR`。一次调谐按以下顺序处理：

1. 停止旧流并记录终止原因，暂停有效数据输出和放音。
2. 校验目标频率，计算高侧 LO、实际合成器配置与 NCO 值，配置预选/增益等。
3. 通过真实状态等待 PLL 锁定并检查配置应答；设置有资料依据的超时，失败报告错误。
4. 等待模拟路径稳定，并清空旧配置缓存、重置滤波/抽取状态、丢弃启动过渡样本。
5. 回读实际编程参数和配置版本，建立新 `stream_id`，开始输出有效 IQ。

稳定判据和超时依器件资料、滤波群时延及实测确定，不使用无依据的固定延时。PLL 失锁或 ADC 失步时停止有效输出，故障恢复必须建立新流，不能只在界面改频率但继续解释旧数据。

### 6.3 跨域、反压和丢样

ADC、DSP 和 USB 本地接口的多位数据跨域采用异步 FIFO/握手，锁定状态等单比特控制适当同步。明确 `valid/ready`，停顿时保持对应数据和控制稳定。

ADC 不能随 USB 反压暂停。缓存满时建议丢新产生的完整 IQ 帧，同时推进生产序号和计划样本索引，累计错误，并在下一帧报告间断；不能悄悄拼接断续数据。严格无丢样模式需判定该次采集失败。

桥接固件须实现枚举、DMA/缓冲、命令应答、取消/复位/断连，不把支持 USB 3.0 枚举等同于持续数据链路完成。GPIO/Bank、跨域及 I/O 约束全部基于所选器件，不猜定引脚。

## 7. USB 数据契约与上位机

### 7.1 沿用的线上格式与新增配置

USB 仍为 SuperSpeed Bulk IN，使用 [直采设计第 6 节](engineering_design_v0.1.md#6-usb-应用协议草案) 的 80 B 帧头、最多 4096 个复数样本、CRC、序号/样本索引、小端 int16 I/Q 及 `value/32768` 数字归一化。这些是两方案共用的待评审草案，尚未实现。主机处理分片与合帧，限制帧长并检查非法字段、CRC 和连续性。

本方案明确 `tuning_center_hz` 表示射频调谐中心，不能填成 10.7 MHz。原直采文档中该值由 NCO 对应，本方案改由 `f_LO - f_NCO` 计算。帧布局保持相同，但设备配置必须包含前端模式，消费端按此解释调谐来源；在正式冻结协议时需要联合更新公共说明和两端实现。

`sample_rate_hz` 仍为抽取后的复数采样率，不是 40 MS/s ADC 速率。以下配置通过命令面回读并随 `config_id` 持久化，不临时占用帧头保留字段：

| 配置 | 内容 |
| --- | --- |
| frontend_mode | `if_10_7_high_side` 等明确模式 |
| rf_requested_hz | 用户要求的目标 RF 频率 |
| lo_frequency_hz | 实际可编程 LO 值，区分名义/校准值，不伪称实测 |
| if_nominal_hz / nco_frequency_hz | 10.7 MHz 名义中频及实际数字本振 |
| adc_sample_rate_hz | ADC 标称/校准采样率及来源 |
| spectrum_corrected | FPGA 已完成高侧频谱校正，主机不再取共轭 |
| analog_gain / filter_id | 增益、衰减、中频/预选与数字滤波配置 |
| reference_calibration | 参考时钟校准、器件/固件版本、配置版本 |

命令至少支持信息/状态查询、配置、启停及明确应答。USB 断连后结束旧流，重新枚举、配置和锁定；检测协商速度，降到 USB 2.0 时本版默认拒绝启动。现有离线 JSON v1 不改格式，只导出连续且方向已校正的基带片段；其中心频率元数据仍表示射频调谐中心。

### 7.2 上位机模块与交互

| 模块 | 内容 |
| --- | --- |
| USB 与设备控制 | 异步接收，RF 调谐、LO/IF/采样率回读，PLL/ADC 状态，超时和重连 |
| 解析与分发 | CRC、帧长、索引检查，有界 DSP/显示/记录队列 |
| 频谱与测量 | 当前通道 FFT/PSD、RF 中心频率估计、有效性和观察区间 |
| 调制处理 | 信号存在性、AM/FM/未知识别，解调、音频滤波和重采样 |
| 音频输出 | 声卡回调、音量、静音、水位、独立时钟漂移处理 |
| 数据管理 | IQ 分块文件、SQL 记录/索引、搜索分类、回放导出 |
| 界面 | RF 调谐输入、设备和 PLL 状态、频谱、测量、录制、历史数据 |

主界面的中心频率输入和频谱坐标均以射频 Hz/MHz 表示，10.7 MHz 只出现在采集配置或诊断信息。PLL 解锁、USB 断连、过载、丢样及录制失败应可见；不能在调谐未完成时显示新的有效测量。

可沿用候选 Python + NumPy/SciPy、Qt/PySide、SQLite、USB SDK/库及成熟音频后端，需按目标系统验证性能和驱动后定型；本次不安装依赖，PyTorch 不是必需条件。

### 7.3 识别、测频、解调与音频

经方向校正后，算法沿用直采基带约定。FFT 需窗函数、归一化和可选平均；`Fs_IQ/N` 是 bin 间隔，不是测量精度。射频估计使用 `f_RF_est = f_LO - f_NCO + f_baseband_est`，不能把中频中心或最大 FFT 峰无条件当作 RF 中心。

AM 可用载波跟踪/峰值插值，FM 结合谱中心或鉴频均值及观测条件估计；记录观察时长、算法版本和有效性。频率误差预算包含 LO 参考及合成误差、ADC 时钟、NCO 量化和估计误差；共享参考可能产生相关误差，应统一推导，不能盲目相加或假定抵消。

先判断信号存在性及过载，再用包络、瞬时频率及谱特征识别，允许 `AM`、`FM`、`unknown`、`no_signal`。AM 首版限常规带载波包络解调；FM 使用相邻复数相位差鉴频并检查相位差混叠，广播去加重按标准配置。不能读取测试真值完成识别。

音频低通后从候选 500 kS/s 重采样到 48 kHz，总比例 12/125；声卡和 ADC 时钟独立，需缓冲反馈或经验证的自适应重采样。调谐、失锁或丢样时重置处理状态并静音/淡入淡出，不能跨缺口鉴频。电脑声卡 DAC 驱动耳机/扬声器，麦克风不作为输出设备。

### 7.4 文件与 SQL

仍采用 IQ 二进制块文件加 SQL 元数据/索引，避免逐样本 SQL 插入。记录采集 UTC 时间、流及样本索引、RF/LO/IF/NCO、ADC/IQ 速率、增益、滤波、校准、频谱校正、算法及设备版本，确保回放时能重现频率解释。

逻辑表沿用 captures、stream_configs、segments、measurements 和 events，补充 PLL 失锁/锁定超时及调谐事件；实际字段、迁移和索引待实现。文件段成功保存后再提交对应索引，保留崩溃恢复检查，SQL 参数化查询，默认不自动删除历史数据。

接收、DSP、记录、界面及音频分开调度。显示可丢过时刷新；DSP 丢积压数据需明确报告并重置状态；录制队列满或磁盘异常应停止该次录制并记录原因。ADC 采样率降低不改变 2 MB/s IQ 录制的空间预算。

## 8. 与射频直采方案比较

| 方面 | 射频直采候选 | 本 10.7 MHz 中频候选 |
| --- | --- | --- |
| ADC 采样率 | 250 MS/s | 40 MS/s |
| ADC 输入频率 | 约 88–108 MHz | 约 10.7 MHz |
| 14 bit 原始负载 | 437.5 MB/s | 70 MB/s |
| FPGA 总抽取 | 500 | 80 |
| 输出 IQ/USB 负载 | 500 kS/s、约 2 MB/s | 相同 |
| 模拟模块 | 预选、驱动、ADC、时钟 | 额外增加混频、PLL、本振及中频滤波/增益 |
| 关键干扰 | RF 采样混叠、强信号动态范围 | RF 镜像、混频杂散、LO 泄漏/相噪，以及 ADC 混叠 |
| 调谐 | 数字 NCO 为主 | PLL 调谐配合数字微调，需等待稳定 |
| 频谱方向 | 数字混频约定 | 高侧注入额外翻转，需校正 |
| 测频误差 | ADC 时钟和估计等 | 再包含本振参考/合成误差 |
| PCB 难点 | 高频采样、时钟与高速 ADC 接口 | 混频/本振隔离、镜像抑制、中频群时延 |
| 成本/功耗 | 高速 ADC 与数字链路压力较大 | 数字压力降低，模拟器件增加；总成本/功耗尚不能断言更低 |

若核心板难以接入高速 ADC，本方案值得优先验证；但是否适合低成本课程制作，必须同时核实 109.4 MHz 附近的镜像抑制和可获得的宽带 10.7 MHz 滤波器，不能只依据采样率降低作决定。

| 验证项 | 内容与证据 |

| 浮点模型 | 合成 AM/FM 经过实数混频、IF 滤波、ADC、DDC 和共轭，验证正负频偏及鉴频极性 |

| 连续运行 | 声卡时钟漂移、水位、丢样统计、功耗/温度、断连与恢复 |
| 结构 | 接口、屏蔽、装配间隙及散热的实物验证 |

镜像测试应在目标 RF 频率和对应镜像频率分别注入已知电平，比较输出，再评估目标与强镜像共存；测试天线接收到节目不能代替定量镜像验证。频率偏差测试至少覆盖正负已知偏移，防止双重取共轭或错用 IF 元数据。

建议顺序：确认需求/仪器与预算，评估预选和 IF 滤波可得性，联合选择本振/混频/ADC/核心板/USB 器件，建立参考模型和调谐契约，贯通模拟数据 USB 链路，完成 PCB、RTL、上位机和实物联调，最后进行系统及结构验收。

分工沿用 `docs/work_plan.md`：HW 负责模拟电路、时钟和 PCB；FPGA-A 负责 ADC、CDC、USB 及控制固件集成；FPGA-B 负责 DDC、方向校正与定点模型；HOST 负责上位机；INT 负责接口协调、结构与验收。USB 固件及 PLL 控制文件归属在建目录前明确。

现有 `python -B -m harness.runner run --jobs 3` 只覆盖已有离线基础，不能验证本方案。新增检查真实可运行后才注册到任务清单，不改变现有 IQ JSON v1，也不把当前 48 kS/s、2 kHz FM 频偏样本当作宽带 FM 验收。
